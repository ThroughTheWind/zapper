# CustomiseFlow

Edit mode screens for spec F8 (US-12 to US-16), built from EditMode, ButtonCatalog, ButtonConfig and PageManager.

- Entered only from the Edit (pencil) button. The top bar becomes Undo · Edit layout · Done, and the page bar appears under it.
- **Catalog:** "+" from the page bar or an empty cell opens the catalog sheet; tap to place in the first free cell (drop target shown), or drag.
- **Button options:** tap any button.
- **Remove:** drag onto the trash zone that replaces the top bar, or tap the remove badge.
- Overflow (not shown): Reset to default, Copy layout from another TV, Export, Import.
