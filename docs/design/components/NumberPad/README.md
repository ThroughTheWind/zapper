# NumberPad

A fixed 3x4 grid of digit keys for direct channel entry.

- Digits 1-9 and 0 are Standard RemoteKeys using `key-numeral` (28/32, 500, tabular figures).
- Bottom-left and bottom-right are Ghost keys: channel list and previous channel by default; both reassignable.
- Span is fixed at 3x4. By default it fills its own "Numbers" page (spec FR-4.1); users can place it on any page.
- No repeat on hold. Haptic `KeyPress` per digit.
