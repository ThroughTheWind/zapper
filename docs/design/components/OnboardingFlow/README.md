# OnboardingFlow

First launch, from welcome to choosing a TV (spec F1, US-1/US-2).

1. **Welcome:** app mark, one-line promise, a single filled "Find my TV" action. No sign-up, no permissions wall: discovery only needs local network access, requested in context.
2. **Discovery:** DiscoveryScan on top, DeviceCards appear as TVs answer. Tapping a card starts pairing. "Add by IP" stays reachable at the bottom.
3. **Not found:** after ~10s the tips Banner replaces the scan; the manual IP TextField probes every adapter and adds whichever answers.
