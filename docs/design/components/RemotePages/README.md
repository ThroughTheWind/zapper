# RemotePages

The Samsung default layout's three pages (spec FR-4.1, US-15) and the text input overlay (F5).

- **Main:** Power · Source · Keyboard · Menu; D-pad with Home, Back, Mute; Volume and Channel rockers around seek, play/pause, Info and Guide.
- **Apps:** 2x1 AppShortcuts from the TV's installed apps, a Label widget, then input/source keys.
- **Numbers:** the NumberPad at 96px cells plus Enter.
- **Text input:** TextInputBar over a scrim; opens automatically when the TV's keyboard appears.
- Swipe between pages; dots under the canvas.
