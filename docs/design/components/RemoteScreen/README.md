# RemoteScreen

The Samsung default layout's Main page, composed from every widget on the 4-column grid at 360dp (72dp cells).

Row by row: Power · Source · Menu · Settings; 3x3 D-pad beside Home, Back, Mute; Volume rocker, Netflix and YouTube shortcuts, Guide and Info, Channel rocker; Rewind · Play/pause (2 cells) · Fast-forward. The page dots show the Main, Apps and Numbers pages (spec FR-4.1). Thumb-heavy keys (D-pad, rockers, play) sit in the lower two-thirds, Power sits top-left away from them.
