# SettingsScreens

Settings as listed in the spec: TVs, Layout, Appearance, Feedback, Controls, About. Built from SettingsControls, DeviceCard and Banner.

- **Root:** one list item per section, each with a summary of its current values.
- **Appearance:** theme segmented button, OLED black switch, colour (Dynamic + 6 presets), key style, and a live preview row. Changes apply instantly.
- **TVs:** saved TVs (overflow: Rename, Set default, Forget) and the selected TV's info (name, IP, MAC, adapter, copy layout).
- **Layout:** edit, reset, export / import through the share sheet.
- Feedback and Controls use the same patterns (see SettingsControls).
